### 🚀 Featured Projects

**[Smart Recipe Hub](https://github.com/ahsan-rajput)** — *3rd Semester Academic Project*
A full-stack recipe management web app with search & filtering, pantry management, weekly meal planning, automatic shopping lists, and ratings/reviews. Built RESTful APIs with Node.js/Express, designed the SQLite schema, and integrated JWT-based auth with role-based admin access.

**Braille to Text Converter** — *Arduino / Embedded Systems Project* 🏆 1st Place, Olympiad 5.0
A Braille-to-text conversion system reading 6-dot Braille input via Arduino digital pins, translating patterns into readable text (alphabets, numbers, capitals, common contractions). Core pattern-recognition logic written in C++.

**Light-Based Communication System** — *Hardware Demonstration Project*
A laser-based Morse code communication system demonstrating secure, line-of-sight message transmission, modeled on a military-base data transmission scenario.
